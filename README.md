# Elevonixs

React + Vite marketing site inspired by [SAS.com](https://www.sas.com/), branded as **Elevonixs**.

## Run locally

```bash
cd elevonixs
npm install
npm run dev
```

Open [http://localhost:5177/elevonixs/](http://localhost:5177/elevonixs/).

## Scripts

- `npm run dev` — local development server
- `npm run build` — production build
- `npm run preview` — preview the production build

## Stack

- React 19 + TypeScript
- React Router
- Vite
